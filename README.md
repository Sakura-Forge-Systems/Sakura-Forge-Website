# Sakura Forge Website

Sakura Forge Systems の会社・事業サイト用リポジトリです。

この README は、Codex 等で初期実装するための構想・要件メモを兼ねます。

## 目的

`sfs.3qra.jp` で公開する、事業紹介・サービス案内・ポートフォリオ導線・問い合わせ導線を持つサイトを管理します。

合同会社さくらフォージシステムズの公式な事業・サービスサイトとして扱います。

## サイトの役割

このサイトは、営業・紹介・信用確認のための入口です。

主な役割:

- Sakura Forge Systems が何を提供するかを伝える
- 小規模店舗・個人事業・小規模事業者が相談しやすい印象を作る
- サンプルHP・ポートフォリオへ自然に誘導する
- 問い合わせ・見積もり相談への導線を作る
- 正式商号・本店所在地・具体的な事業内容を確認できるようにする

## 初期方針

- 正式商号は `合同会社さくらフォージシステムズ` とする。
- 本店所在地は `〒542-0081 大阪府大阪市中央区南船場3丁目2番22号おおきに南船場ビル205` とする。
- 個人情報、本人確認書類、契約書原本、証明書PDF、銀行情報、APIキー等は置かない。
- 外部公開前に、掲載文言・問い合わせ先・法務/税務上の表現を確認する。
- サービス料金・契約条件・支払い条件は、初期公開時点では断定しすぎない。
- 見積もり・対応範囲・納期・修正方針・支払い条件は、案件ごとに事前確認する前提にする。

#### 小規模店舗向けホームページ制作

説明案:

#### AI・Web活用相談

説明案:

> AIツールやWebサービスを、日々の作業にどう取り入れるかを一緒に整理します。難しいシステム導入ではなく、まずは問い合わせ対応、文章作成、情報整理など、身近なところから相談できます。

#### コーディング・開発支援

説明案:

> 静的サイト、LP、簡単なWebツール、既存サイトの修正など、必要な範囲に絞った開発支援を行います。要件整理から実装方針の相談まで対応します。

説明案:

> VPSやドメイン、メール、公開環境まわりの設定を支援します。継続費用や管理者権限の扱いを事前に確認し、無理のない運用を目指します。

#### Minecraftサーバー設営支援

説明案:

> 小規模コミュニティ向けのMinecraftサーバー設営や運用相談に対応します。用途・人数・必要なMOD・管理方法を整理したうえで構成を提案します。

#### AI動画編集支援

説明案:

> AIツールを活用した動画編集・素材作成・作業効率化の相談に対応します。公開用途や権利関係に注意しながら、使える範囲を一緒に整理します。

### 5. Process / 相談から制作までの流れ

初期案:

1. お問い合わせ・相談
2. 内容と目的の整理
3. 構成・見積もり・納期の確認
4. 制作開始
5. 確認・修正
6. 公開または納品
7. 必要に応じて保守・改善

注意文言:

> 正式な制作開始前に、対応範囲・費用・納期・修正回数・支払い条件を確認します。

### 6. Policy / 対応方針

入れたい内容:

- 依頼内容を確認したうえで対応可否を判断する
- 公序良俗に反する案件、権利関係が不明確な案件、法的に問題のある案件は対応しない
- 専門資格が必要な内容は、Web制作・情報整理の範囲で対応し、法的助言などは行わない
- 素材提供がある場合、権利確認は依頼者側で済んでいる前提
- 生成AIやフリー素材を使う場合は、用途・権利・表記を確認する

短めの掲載文言案:

> ご相談内容によっては、対応をお断りする場合があります。権利関係が不明確な素材、法令に抵触する可能性がある内容、公序良俗に反する内容はお受けできません。専門資格が必要な内容については、必要に応じて専門家への確認をお願いする場合があります。

## デザイン方向

### 雰囲気

- 落ち着いた和モダン寄り
- 桜・鍛造・工房感を少しだけ入れる
- 技術企業らしい清潔感
- 小規模店舗が怖がらない柔らかさ

### 色の方向

候補:

- 背景: あたたかい白 / 生成り
- メイン: 深い墨色 / 濃紺 / ダークブラウン
- アクセント: 桜色、薄い金色、銅色
- サブ: グレー、淡いベージュ

### UI

- スマートフォン優先
- CTAは多すぎない
- サービスカード形式
- サンプルへの導線を目立たせる
- 会社情報はフッターで確認しやすく表示する

## 技術方針

初期候補:

1. 静的HTML/CSS
2. Astro
3. Next.js

おすすめ:

- 初期は **Astro** か **静的HTML/CSS**。
- 会社サイトは軽量・高速・保守しやすい構成を優先。
- ブログや実績記事を増やすなら Astro が扱いやすい。
- 単発LPとして早く出すなら静的HTML/CSSで十分。
